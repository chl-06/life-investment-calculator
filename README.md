# Life Investment Calculator

把你每天做的事情当成投资组合来评估——哪些是"高增长资产"、哪些是"折旧资产"、哪些是"负债"。

## 功能

- 添加每日行为并分类（增值 / 社交 / 维护 / 娱乐 / 消耗 / 损耗 / 杂务）
- ROI 综合评分 + 信用评级（优秀 → 堪忧）
- 时间资产配置分析（各类占比可视化）
- 年化复利计算 + 不良率预警
- 个性化优化建议
- 6 个预设人生模板一键填充（打工人 / 卷王 / 躺平 / 自律达人 / 人生赢家）

## 技术栈

纯前端 · 单页 HTML · 无依赖 · 浏览器直接打开即可使用
